# 밝기 선형 정책과 /100 누락

ZCL R8 §3.19.2.2.1은 조명 CurrentLevel의 1=최소, 254=최대, 0 미사용, 255=undefined를 정의합니다. 중간 단계는 application specific gradations입니다. TS-0023 v5.7.0 §5.3.1.17 brightness는 정수 pct, 0%=최소·100%=최대를 정의합니다.

이 두 범위를 선형으로 대응하기로 채택할 때의 구현 정책은 다음과 같습니다.

```
p = round(100 * (L - 1) / 253)
L = 1 + round(253 * p / 100)
```

`p`는 0~100 정수 백분율입니다. 0→1, 100→254이며, 양수에서 .5를 올리는 반올림을 채택하면 50→128입니다. 반올림 동률 규칙은 언어의 기본 round에 맡기지 말고 승인 명세에 명시해야 합니다. 254개의 source 값이 101개의 정수 백분율로 줄어들므로 왕복 시 원래 L의 완전 복원은 보장되지 않습니다.

04-A-low-r5의 원문 proposed_policy에는 `L=1+round(p×253)`으로 /100이 누락됐습니다. p=100이면 25301이므로 범위를 벗어납니다. 원문은 그대로 보존했고, 위 수정은 별도 해설입니다. 앞선 탐색 02-medium-r1에서도 동일 유형을 관측했지만 본분석 밖입니다.

공식은 확인한 표준 조항의 직접 인용이 아니라 범위·끝점 의미를 이용한 선형 정책입니다. 광학적 밝기 또는 사용자 지각이 선형이라는 증거가 아닙니다. 0%를 Off로 바꾸지 않는 의미 대응과 실제 명령의 with-On/Off 선택은 구분해야 합니다. 장치의 지원 범위·곡선·정밀도·꺼진 상태 동작은 미확인입니다. 범위 밖 값·undefined 처리도 승인 대상입니다.
